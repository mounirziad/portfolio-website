Nature's Solace

Unity C# Environmental Team Leadership Game Design
World Transformation: Dynamic color restoration system that transitions the environment from grayscale to vibrant colors based on player progress
Interactive Growth: Plant watering mechanics with real-time growth animations and visual feedback systems
Character Environment: Smooth player controller with atmospheric audio and interaction systems in the cabin hub

Project Overview

Nature's Solace is a meditative environmental experience that explores the bond between human emotion and the natural world. As Team Lead Developer at Studio Friendship, I orchestrated the technical vision for this immersive journey where players restore color and life to a grayscale world through emotional connection with nature.

The project combines sophisticated technical systems with emotional storytelling, featuring dynamic world transformation, interactive plant growth mechanics, and a seamless player experience that evolves based on player interaction.

Core Technical Systems

🌱 Dynamic Plant Growth System

Interactive plant mechanics that respond to player actions with smooth animations and visual feedback.

C#
public class PlantGrowth : MonoBehaviour { [Header("Growth Settings")] public float growthAmount = 0.1f; // Growth per water interaction public float maxScale = 2f; // Maximum plant size public float growthDuration = 1f; // Animation timing private Vector3 targetScale; private bool isGrowing; private float growthProgress; private void OnTriggerEnter(Collider other) { if (other.gameObject.layer == LayerMask.NameToLayer("Water")) { GrowPlant(); playerManager.SetSpirit(10f); // Reward player Destroy(other.gameObject); // Remove water sphere } } public void GrowPlant() { if (transform.localScale.x >= maxScale) return; targetScale = Vector3.Min( transform.localScale + (Vector3.one * growthAmount), initialScale * maxScale ); growthProgress = 0f; isGrowing = true; // Smooth growth animation with optional wiggle effect transform.localScale = Vector3.Lerp( transform.localScale, targetScale, growthProgress ); } }

🎨 World Color Transformation

Dynamic material system that transitions the world from grayscale to vibrant colors based on player progress.

C#
public class ChangeMaterial : MonoBehaviour { private Renderer objectRenderer; private Material objectMaterial; private IEnumerator GrayToColor() { float elapsedTime = 0f; float timeToChange = 2f; while (elapsedTime < timeToChange) { elapsedTime += Time.deltaTime; // Smooth saturation transition from 0 (grayscale) to 1 (full color) objectMaterial.SetFloat("_saturation", Mathf.Lerp(0, 1, elapsedTime / timeToChange) ); yield return null; } } void Update() { // Activate color transformation when player achieves milestones if (gameManager.GetComponent().inColor == true) { StartCoroutine(GrayToColor()); } } }

🚶 Advanced Player Controller

Smooth character movement with audio feedback, interaction systems, and save/load functionality.

C#
public class PlayerMovement : MonoBehaviour { [Header("Movement")] public float speed; public Vector2 move; private Rigidbody rb; [Header("Audio")] [SerializeField] private AudioSource footsteps; private bool isMoving = false; void MovePlayer() { Vector3 moveDirection = orientation.forward * move.y + orientation.right * move.x; rb.linearVelocity = moveDirection * speed; // Dynamic audio system bool wasMoving = isMoving; isMoving = move.magnitude > 0.1f; if (isMoving && !wasMoving) { footsteps.loop = true; footsteps.Play(); // Start footsteps when moving } else if (!isMoving && wasMoving) { footsteps.loop = false; footsteps.Stop(); // Stop when stationary } } // Save system integration public void Save(ref PlayerSaveData data) { data.Position = transform.position; data.Spirit = currentSpirit; } }
