S.O.R.N.

Unreal Engine C++ Gameplay Systems Third-Person Combat Team Project

Gameplay footage highlighting high-speed mech movement, lock-on combat, and mission flow.

High-Mobility Combat: Fast-paced third-person mech movement with boost-driven traversal and evasive maneuvers
Lock-On Gunplay: Target-focused combat flow designed for readability and mechanical precision
Mission Structure: Modular objectives supporting sabotage, combat encounters, and extraction

Project Overview

S.O.R.N. is a third-person mech action game focused on high-speed movement, lock-on–driven combat, and tightly structured mission gameplay. Developed as a large team passion project, the game emphasizes mechanical clarity, player expression through mobility, multiplayer compatibility, and modular gameplay systems.

My contributions centered on gameplay programming and systems design, supporting movement states, combat flow, dialogue systems, and data-driven mission logic within Unreal Engine — all built with multiplayer compatibility and gameplay bus functionality in mind.

Core Gameplay Systems

🤖 Mech Movement & State Logic

High-mobility traversal system supporting boosts, strafing, and rapid directional changes, designed to maintain responsiveness during combat.

C++
// Simplified movement state handling void ASornMech::HandleMovementState() { if (bIsBoosting) { CurrentSpeed = BoostSpeed; } else { CurrentSpeed = BaseSpeed; } }

🎯 Lock-On Combat Flow

Target-locking system built to support readable encounters, weapon accuracy, and consistent camera framing during combat.

C++
// Target acquisition logic void ASornCombatComponent::LockOnTarget(AActor* NewTarget) { CurrentTarget = NewTarget; bIsLockedOn = (CurrentTarget != nullptr); }

🧠 Mission & Objective Systems

Data-driven mission logic allowing objectives to be chained, failed, or completed dynamically during gameplay.

C++
// Mission state progression void UMissionComponent::AdvanceObjective() { CurrentObjectiveIndex++; OnObjectiveUpdated.Broadcast(CurrentObjectiveIndex); }

🏗️ Modular Gameplay Architecture

Component-based design enabling parallel development and rapid iteration across movement, combat, and AI systems.

C++
UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent)) class USornCombatComponent : public UActorComponent { GENERATED_BODY() };
